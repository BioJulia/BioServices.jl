UniProt

UniProt is a database of protein sequences and functional annotation. BioServices.UniProt is an interface to the UniProt REST API hosted at https://rest.uniprot.org.

Getting Started

Import module:

using BioServices.UniProt

Every function returns an HTTP.Response; the data is in res.body. The format of the data is set by the format query parameter, e.g. "json", "fasta", "tsv", "list", "xml", or "txt". With format="json", the body can be parsed with a JSON library such as JSON.jl.

Other query parameters are passed as keyword arguments. Parameters that accept comma-separated lists, such as fields, can also be given as vectors.

Datasets

The dataset keyword selects which UniProt database to query. The default is "uniprotkb"; others include "uniref", "uniparc", "proteomes", "genecentric", "taxonomy", "keywords", "citations", "diseases", "database", "locations", "unirule", "arba", and "unisave".

Examples

Retrieve entries

julia> res = uniprotentry("P08069"; format="fasta");

julia> print(String(res.body))
>sp|P08069|IGF1R_HUMAN Insulin-like growth factor 1 receptor OS=Homo sapiens OX=9606 GN=IGF1R PE=1 SV=1
MKSGSGGGSPTSLWGLLFLSAALSLWPTSGEICGPGIDIRNDYQQLKRLENCTVIEGYLH
...

julia> res = uniprotentries(["P08069", "P35626"]; format="fasta");

Search

The query syntax is described in the UniProt help. fields selects the columns returned in tsv format.

julia> res = uniprotsearch("id:T2R38_MOUSE"; fields="accession", format="tsv");

julia> print(String(res.body))
Entry
Q7TQA6

julia> res = uniprotsearch("gene_exact:IGF1R AND reviewed:true"; fields=["accession", "organism_name"], format="tsv");

Search results are paginated, with at most 500 results per page (set by size). The total number of results is in the X-Total-Results header, and uniprotnext retrieves the following page:

res = uniprotsearch("gene_exact:IGF1R"; format="list", size=100)
accessions = String[]
while res !== nothing
    append!(accessions, split(String(res.body)))
    res = uniprotnext(res)
end

Alternatively, uniprotstream returns all results in a single response.

ID mapping

ID mapping converts identifiers between databases. It runs as a job on the server: submit it, poll until it finishes, then retrieve the results.

julia> using JSON

julia> res = uniprotidmapping(["ENSMUSG00000067064", "ENSMUSG00000057464"]; from="Ensembl", to="UniProtKB");

julia> jobid = JSON.parse(String(res.body))["jobId"];

julia> while uniprotidmappingstatus(jobid).status != 303   # 303 indicates that the job has finished
           sleep(1)
       end

julia> res = uniprotidmappingresults(jobid; dataset="uniprotkb", fields=["accession", "id"], format="tsv");

julia> print(String(res.body))
From	Entry	Entry Name
ENSMUSG00000067064	Q8VGU4	Q8VGU4_MOUSE
ENSMUSG00000057464	A0A0N4SV77	A0A0N4SV77_MOUSE
ENSMUSG00000057464	Q7TQS4	Q7TQS4_MOUSE

A job that fails makes uniprotidmappingstatus throw an HTTP.StatusError. uniprotidmappingfields lists the supported from and to databases.

Identifiers

These functions parse UniProt identifiers locally, without contacting the service. uniprotaccession extracts the accession from an accession with an isoform or version suffix, from the entry name of an unreviewed entry, or from a FASTA header:

julia> uniprotaccession("Q8VGW6_MOUSE")
"Q8VGW6"

julia> isuniprotaccession("Q8VGW6")
true

The entry names of reviewed (Swiss-Prot) entries contain a mnemonic protein code instead of the accession:

julia> uniprotentryname("IGF1R_HUMAN")
(protein = "IGF1R", species = "HUMAN")

julia> res = uniprotsearch("id:IGF1R_HUMAN"; fields="accession", format="list");

julia> String(res.body)
"P08069\n"

uniprotfastaheader splits a FASTA header into its fields:

julia> res = uniprotentry("P08069"; format="fasta");

julia> uniprotfastaheader(first(eachline(IOBuffer(res.body))))
(db = "sp", id = "P08069", entryname = "IGF1R_HUMAN", proteinname = "Insulin-like growth factor 1 receptor", organism = "Homo sapiens", taxid = 9606, gene = "IGF1R", existence = 1, version = 1)

Methods

BioServices.UniProt.uniprotentry — Function
uniprotentry(id; dataset="uniprotkb", subset=nothing, params...)

Retrieve a single entry from dataset.

Calls the endpoint "<dataset>/<id>", or "<dataset>/<id>/<subset>" if subset is set.

dataset may be "uniprotkb", "uniref", "uniparc", "proteomes", "genecentric", "taxonomy", "keywords", "citations", "diseases", "database", "locations", "unirule", "arba", or "unisave".

subset selects a sub-resource of the entry, e.g. "light" (uniref, uniparc), "members" (uniref), "databases" (uniparc), or "status" (unisave).

Query Parameters: format, fields, version (uniprotkb); see the UniProt API documentation for the parameters accepted by each dataset and subset.

Examples

julia> res = uniprotentry("P08069"; format="fasta");

julia> res = uniprotentry("9606"; dataset="taxonomy", format="json");
source

uniprotentries(ids; dataset="uniprotkb", params...)

Retrieve the entries listed in ids (a vector or a comma-separated string) from dataset, which must be "uniprotkb", "uniparc", or "uniref".

Results are paginated; see uniprotnext.

BioServices.UniProt.uniprotsearch — Function
uniprotsearch(query; dataset="uniprotkb", params...)

Search dataset using the UniProt query syntax, e.g. "gene:IGF1R AND organism_id:9606".

Calls the endpoint "<dataset>/search". Results are paginated: size (at most 500) sets the number of results per page, and uniprotnext retrieves the following page. The total number of hits is in the "X-Total-Results" response header. Use uniprotstream to retrieve all results at once.

Query Parameters: format, fields, size, sort, includeIsoform, cursor

Examples

julia> res = uniprotsearch("id:T2R38_MOUSE"; fields="accession", format="tsv");

julia> print(String(res.body))
Entry
Q7TQA6

BioServices.UniProt.uniprotstream — Function
uniprotstream(query; dataset="uniprotkb", params...)

Search dataset and return all results in a single response.

Calls the endpoint "<dataset>/stream". This is appropriate for queries with many results, but the request may take a long time to complete for very large result sets. See uniprotsearch for the query syntax.

Query Parameters: format, fields, sort, includeIsoform, download

BioServices.UniProt.uniprotnext — Function
uniprotnext(res::HTTP.Response)

Retrieve the next page of a paginated result res, as returned by uniprotsearch, uniprotentries, or uniprotidmappingresults. Returns nothing if res is the last page.

Examples

res = uniprotsearch("gene:IGF1R"; format="list", size=100)
while res !== nothing
    # process String(res.body)
    res = uniprotnext(res)
end

BioServices.UniProt.uniprotidmapping — Function
uniprotidmapping(ids; from="UniProtKB_AC-ID", to="UniProtKB", taxId=nothing)

Submit an ID mapping job converting ids (a vector or a comma-separated string) from the database from to the database to. taxId restricts the mapping to a taxon, and is accepted only for some from databases.

The body of the response is JSON containing the jobId, which is passed to uniprotidmappingstatus and uniprotidmappingresults. The supported from/to pairs are listed by uniprotidmappingfields.

Examples

julia> res = uniprotidmapping(["ENSMUSG00000067064", "ENSMUSG00000057464"]; from="Ensembl");

julia> jobid = JSON.parse(String(res.body))["jobId"];

BioServices.UniProt.uniprotidmappingstatus — Function
uniprotidmappingstatus(jobid)

Check the status of the ID mapping job jobid.

While the job is in progress, the response status is 200 and its JSON body has a jobStatus field (e.g. "NEW", "RUNNING"). Once the job has finished, the response status is 303 (redirect to the results), and the results can be retrieved with uniprotidmappingresults.

A job that failed raises an HTTP.StatusError; its body describes the error.

source
BioServices.UniProt.uniprotidmappingresults — Function
uniprotidmappingresults(jobid; dataset=nothing, stream=false, params...)

Retrieve the results of the ID mapping job jobid.

When dataset is nothing, the results are pairs of from and to identifiers. When dataset is "uniprotkb", "uniparc", or "uniref" (matching the to database of the job), the results include the full entries, which can be filtered with query and formatted with format and fields.

If stream is false, the results are paginated (see uniprotnext); otherwise they are returned in a single response.

Query Parameters: format, fields, query, size, sort, includeIsoform, download

BioServices.UniProt.isuniprotaccession — Function
isuniprotaccession(s)

Return true if s is a UniProtKB accession, e.g. "P08069" or "A0A023GPI8". Isoform ("P05067-2") and versioned ("P05067.3") identifiers return false; use uniprotaccession to extract the accession from them.

source
BioServices.UniProt.uniprotaccession — Function
uniprotaccession(s)

Extract the UniProtKB accession at the start of s. s may be

  • an accession, optionally with an isoform or version suffix ("P05067-2", "Q8VGW6.37");
  • an entry name of an unreviewed (TrEMBL) entry, e.g. "Q8VGW6_MOUSE";
  • a UniProtKB FASTA header, e.g. ">sp|P08069|IGF1R_HUMAN Insulin-like growth factor 1 receptor OS=...";
  • any of the above followed by '_', '|', or whitespace and other text.

Isoform and version suffixes are removed. Throws an ArgumentError if s does not start with an accession. In particular, the entry name of a reviewed (Swiss-Prot) entry, such as "IGF1R_HUMAN", does not contain the accession; uniprotsearch can find it.

Examples

julia> uniprotaccession("Q8VGW6_MOUSE")
"Q8VGW6"

julia> uniprotaccession("sp|P05067-2|A4_HUMAN Isoform APP305 of Amyloid-beta precursor protein OS=Homo sapiens OX=9606 GN=APP")
"P05067"
source
BioServices.UniProt.uniprotentryname — Function
uniprotentryname(s)

Split the UniProtKB entry name s, of the form "X_Y", into a named tuple (; protein = X, species = Y). For reviewed (Swiss-Prot) entries, X is a mnemonic protein code of at most 5 characters; for unreviewed (TrEMBL) entries, it is the accession. Y is the mnemonic species code.

Throws an ArgumentError if s is not an entry name. To obtain the entry name from a FASTA header, use uniprotfastaheader.

Examples

julia> uniprotentryname("IGF1R_HUMAN")
(protein = "IGF1R", species = "HUMAN")
source
BioServices.UniProt.uniprotfastaheader — Function
uniprotfastaheader(s)

Parse the header line s of a UniProtKB FASTA record, with or without the leading '>'. Returns a named tuple with fields

  • db: "sp" (reviewed, Swiss-Prot) or "tr" (unreviewed, TrEMBL)
  • id: the accession, or the isoform identifier (e.g. "P05067-2") for an isoform
  • entryname: the entry name, see uniprotentryname
  • proteinname: the recommended protein name
  • organism: the scientific name of the organism (OS)
  • taxid: the NCBI taxonomy identifier of the organism (OX), an Int
  • gene: the gene name (GN), or nothing
  • existence: the protein existence level (PE), an Int from 1 to 5, or nothing
  • version: the sequence version (SV), an Int, or nothing

GN is absent when the entry has no gene name; PE and SV are absent for isoforms. Throws an ArgumentError if s is not a UniProtKB FASTA header.

Examples

julia> uniprotfastaheader(">sp|P08069|IGF1R_HUMAN Insulin-like growth factor 1 receptor OS=Homo sapiens OX=9606 GN=IGF1R PE=1 SV=1")
(db = "sp", id = "P08069", entryname = "IGF1R_HUMAN", proteinname = "Insulin-like growth factor 1 receptor", organism = "Homo sapiens", taxid = 9606, gene = "IGF1R", existence = 1, version = 1)
